## 一、这个项目是做什么的？

**一句话**：一个电商运营人员的 AI 助手，运营人员用自然语言提问，Agent 自动调用工具查数据、生成文案、查知识库。

举个例子，运营人员可以直接在聊天框里说：

```
"7月15号到今天，充电宝卖了多少？"
"帮我生成苹果15的三条淘宝标题"
"退货要多久，运费谁出？"
```

Agent 会自动：

1. 理解意图 → 决定调哪个工具
2. 调用工具查数据 / 生成内容 / 检索知识库
3. 综合分析 → 给出完整回答

> 重点：**这不是一个一问一答的聊天机器人**，而是一个能**自主规划、多步执行**的 Agent。

---

## 二、给谁用？解决什么问题？

**给谁用**：电商运营人员（内部使用，不是给顾客的）

**解决什么问题**：

- 运营查销售数据，不用再翻后台、写 SQL
- 运营写文案，不用从零憋字
- 运营答售后问题，不用翻文件夹找政策文档

## 四、技术栈与为什么选它们

| 层级 | 技术 | 为什么选 |
|---|---|---|
| 后端框架 | FastAPI + Uvicorn | 异步性能好，自带 Swagger 文档 |
| LLM | 通义千问 DashScope | 国内可用，接口可切换 |
| 向量库 | Qdrant | 本地模式免部署，开发方便 |
| 数据库 | SQLite（开发）→ PostgreSQL（上线） | 开发简单，零配置 |
| ORM | SQLAlchemy 2.0 异步 | 原生支持 async |
| 前端 | React + TypeScript + Ant Design | 生态成熟，组件齐全 |

## 五、整体架构

```
用户（运营人员）
    │  自然语言提问
    ▼
[前端] React 聊天界面
    │  HTTP / SSE
    ▼
[API层] FastAPI
    │
    ▼
[Agent层] ReActAgent（while 循环，自主决定调工具）
    │  │
    │  ├─→ [工具1] 销售查询 ──→ SQLite
    │  ├─→ [工具2] 文案生成 ──→ LLM
    │  ├─→ [工具3] 知识库检索 ──→ Qdrant
    │  └─→ [工具4] 库存预警 ──→ SQLite
    │
    ▼
[LLM层] 通义千问（抽象接口，可切换）
```

**三层依赖关系**（这是整个项目的灵魂）：

```
Tool 层   ← Function Calling 的"手" —— 执行具体操作
Agent 层  ← 编排 + 决策的"大脑" —— 决定调什么、调几次
LLM 层    ← 思考的"发动机" —— 提供智能
```

## 七、怎么运行这个项目

```bash
# 1. 配置环境变量（.env）
DASHSCOPE_API_KEY=你的key
JWT_SECRET_KEY=一串随机字符串

# 2. 初始化数据库 + 模拟数据
python scripts/init_db.py
python scripts/seed_data.py

# 3. 构建知识库（RAG）
python scripts/build_kb.py

# 4. 启动后端
uvicorn backend.api.app:app --host 0.0.0.0 --port 8000

# 5. 启动前端
cd frontend
npm install
npm run dev
```
