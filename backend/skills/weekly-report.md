# 经营周报

## 口径（每次都按这四条走，不要自己增减维度）

1. **销售概览**：本周期的销售额和订单数，**必须同时取上一周期做环比对照**（`query_sales`）
2. **类目拆解**：哪个类目涨、哪个跌（`category_query`），用来区分"大盘整体下滑"还是"单个类目拖累"
3. **库存风险**：缺货商品清单（`check_stock`）—— 缺货是最常见的销量下滑原因，
   少这一步会把"卖不动"和"没得卖"混为一谈，这是周报最容易犯的错
4. **会员结构**：各等级的订单数 / 人均消费（`user_profile`），判断高价值客户有没有流失

## 输出要求

- 报告分四段：**本期概览 → 变化归因 → 风险提示 → 下期建议**
- 每个数字都要写明**来自哪个工具、哪个时间段**，不许估算或推测数字
- 归因必须有数据支撑，例如"类目 A 环比掉了 30%，是整体下滑的主因"；
  写成"可能因为市场行情"这种没有数据支撑的猜测就等于没做分析

## 注意

- **环比对照是必须的**：没有对照的周报只有数字、没有判断，等于把查询结果复述一遍
- 某个维度取不到数据时，明确写"该维度未取到数据"，不要用别的维度凑一个看起来完整的结论
