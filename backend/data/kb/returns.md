# 退货政策

## 退货条件
- 商品签收后 **7 天内** 可申请退货
- 商品必须保持原包装完整，配件齐全
- 食品、内衣、定制商品不支持退货

## 退货流程
1. 用户在 APP 或网站提交退货申请
2. 系统自动审核（24 小时内）
3. 审核通过后，用户自行寄回商品
4. 仓库收到退货后 3 个工作日内退款
5. 退款原路返回（支付宝/微信/银行卡）

## 运费规则
- 商品质量问题：商家承担来回运费
- 非质量问题（如不喜欢）：用户承担退货运费
- 平台赠送运费险的商品可获赔 8-12 元

## 特殊情况
- 大件商品（超过 20kg）：上门取件，无需自行寄回
- 跨境商品：退货周期延长至 15 天
- 换货：走正常退货流程后重新下单
